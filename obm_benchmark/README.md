# obm_benchmark: ALLUVSIM-based ground truth (ResMill ChannelLayer)

## Purpose

The existing benchmark truths are generated with SGS (`src/truth_model.py`). A
benchmark generated by SGS may favour variogram-based reconstruction, because
its covariance structure and distribution match the method's assumptions. This
workflow builds a second, **independently generated channelized ground truth**
family: **event-based fluvial realizations** from ResMill's `ChannelLayer`, which
implements the ALLUVSIM methodology (Pyrcz et al., 2009). These are
**ALLUVSIM-based ground truths** for a robustness test of the data-generating
mechanism. They are not field-calibrated models.

Terminology: use "event-based fluvial realization", "channelized reservoir
realization", "ALLUVSIM-based ground truth", "independently generated channelized
ground truth". `ChannelLayer` is event-based / pseudo-process-based; do not
describe these fields as exact geological truth, fully process-based models, or
strict Boolean OBM. `GaussianLayer` is not used anywhere in this workflow.

Scope of this step: ground-truth generation, automated QC, manifest, and a
descriptive comparison with the SGS truths. Sampling masks, estimation runs and
evaluation metrics are later steps.

## Design (frozen in `config/cb_jigsaw.yaml` before results were inspected)

| Item | Value |
|---|---|
| Generator | `resmill.ChannelLayer`, preset `CB_JIGSAW` (unmodified), default `FACIES_PROPS` |
| Grid | nx=ny=50, nz=16; 1000 m x 1000 m x 16 m (20 m x 20 m x 1 m cells), top_depth 0. This matches the existing SGS benchmark (50 x 50 cells of 20 m). The brief's 128 x 128 x 10 m default was changed to this grid. |
| Porosity texture | `poro_noise_std=0.08`, `poro_noise_range=5.0` |
| Physical range (QC) | [0.0, 0.5] |
| 2D slice rule | `slice_index = nz // 2 = 8`, the same for every seed |
| Units | each 2D slice is affine-rescaled per realization to mean 15.0 / std 3.0 (%), the `POR_MEAN`/`POR_STDEV` of `src/experiments/base_case.py`: `truth = (x - mean(x)) * (3/std(x)) + 15`, std ddof=0 (same as `GSLIB.affine`) |
| Geological seeds | 0 to 29 (`start: 0`, `stop_exclusive: 30`), all generated |
| Diagnostic seeds | 0, 10, 20 |

### Array conventions

* `*_3d.npy`: native ResMill layout `(nx, ny, nz)` indexed `[ix, iy, iz]`. x increases with ix and y increases with iy.
* `*_2d*.npy`: project convention `(ny, nx)`, row 0 = max-y, column = ix,
  i.e. `np.flipud(arr3d[:, :, 8].T)`. This is the same as the SGS truths (`src/truth_model.py`).
  `tests/test_obm_helpers.py` and a runtime self-check verify the mapping.

### Outputs per run: `results/raw/obm_ground_truth/<timestamp>/`

Per seed (stem `cb_jigsaw_seed_NNN`):

| File | dtype / shape | Content |
|---|---|---|
| `<stem>_porosity_3d.npy` | float32 (50,50,16) | native porosity, fraction |
| `<stem>_facies_3d.npy` | int8 (50,50,16) | facies codes |
| `<stem>_porosity_2d_frac.npy` | float32 (50,50) | slice k=8, fraction, project convention |
| `<stem>_facies_2d.npy` | int8 (50,50) | slice k=8, project convention |
| `<stem>_truth_2d.npy` | float64 (50,50) | rescaled porosity %, project convention (the benchmark truth) |

Run-level files: `qc_summary.csv`, `diag_<stem>.png` (diagnostic seeds), `config_used.yaml`, and `manifest.json`.
`manifest.json` holds the standard fields (`experiment`, `timestamp`, `git_commit`,
`git_dirty`, `params`, `seed`, `code_entrypoint`, `output_files`). It also records the Python version, the
ResMill version and git commit, the full config, `FACIES_PROPS`, the preset values, and per-realization
records: stats, facies proportions, net-to-gross, affine a/b, porosity mean by facies, QC results, and file sha256.
It also lists `excluded_realizations` with reasons, the determinism check result, and QC counts.

Facies codes: -1 FF overbank fines, 0 FFCH mud plug, 1 CS crevasse splay, 2 LV levee,
3 LA lateral accretion, 4 CH channel. Net = code >= 1.

### Automated QC (brief section 9)

The rules are defined in the config. **Exclusion rules** exclude a realization and log the reason:
shape, finite values, porosity within [valid_min, valid_max], valid facies codes,
non-degenerate slice (std > 0), and no duplicate 3D realization across seeds (sha256 match).
**Fatal checks** abort the run, because they indicate a pipeline bug:
the saved 2D arrays must equal the transformed `3D[:, :, 8]`, the files must match the manifest (sha256, no unlisted files),
and a regenerated seed 0 must be bit-identical (determinism).
The diagnostic plots for seeds 0, 10 and 20 show: the porosity slice, the facies slice, a histogram, porosity by facies,
x/y variograms, and a connectivity map. The connectivity map uses native porosity >= 0.18 (CS base value) with 4-connectivity.
Diagnostics are never used to keep or drop seeds.

## Environment

ResMill needs Python >= 3.10, so this workflow uses its own venv. The project `.venv` is Python 3.8.
ResMill is pinned to a git commit; the PyPI release is not used.

```bash
uv python install 3.11
uv venv .venv-obm --python 3.11
uv pip install --python .venv-obm/Scripts/python.exe -r obm_benchmark/requirements-obm.txt
```

## Exact rerun commands (from the repository root)

```bash
# 1. Generate the 30 realizations + in-process QC + manifest   (.venv-obm, ~1 min)
.venv-obm/Scripts/python.exe -m obm_benchmark.scripts.generate_ground_truth
#    optional: --config obm_benchmark/config/cb_jigsaw.yaml

# 2. Read-only re-verification of a run (default: latest run); exit code 1 on any disagreement
.venv-obm/Scripts/python.exe -m obm_benchmark.scripts.run_qc [results/raw/obm_ground_truth/<timestamp>]

# 3. Descriptive comparison with the 5 base-case SGS truths   (project .venv, py3.8)
.venv/Scripts/python.exe -m src.experiments.compare_obm_vs_sgs_truth [--obm-run-dir DIR]
#    -> results/processed/obm_vs_sgs_truth/

# Tests of the orientation / rescale / variogram helpers
.venv/Scripts/python.exe -m pytest tests/test_obm_helpers.py
```
